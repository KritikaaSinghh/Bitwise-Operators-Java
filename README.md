# Bitwise Operators - Java

A collection of Java programs for learning and practicing **Bitwise Operators** and **Bit Manipulation** concepts.

## Topics Covered

- Bitwise AND (`&`)
- Bitwise OR (`|`)
- Bitwise XOR (`^`)
- Bitwise NOT (`~`)
- Left Shift (`<<`)
- Right Shift (`>>`)
- Unsigned Right Shift (`>>>`)
- Set Bits
- Power of 2
- Power of 4
- XOR-based problems
- Bit Manipulation
- Fast Exponentiation
